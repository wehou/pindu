# PhonicsQuest · 小学生自然拼读闯关

一个面向小学生的自然拼读（Phonics）学习页面，单文件 HTML，无需联网、无需安装，双击 `index.html` 即可在浏览器中使用。

## 特点

- **由易到难，10 个阶段**：字母音 → 短元音与 CVC 拼读 → 辅音二合字母 → 辅音连缀 → 魔法 e → 元音组 → r 控制元音与双元音 → 音节/重音/弱读 → 词尾与拼写通则 → 静默字母与高频不规则词。
- **每个阶段固定三段**：
  1. 🎮 **玩儿法** —— 目标、准备、四步流程、口诀、用时、过关标准、家长提示；
  2. 📖 **学一学** —— 本阶段全部知识点总表，可展开看嘴型/发音要领/全部例词（点词即读）；
  3. ✏️ **练一练** —— 按知识点**穷举**生成的关卡，做完即覆盖本阶段全部内容。
- **规模**：295 个知识点 · 49 个关卡 · 493 道题，13 种题型（听音选字母、组合→音、音→单词、合音拼词、听音辨词、音节类型、敲重音、词尾发音、静默字母、不规则词……）。每题答错必给「为什么」。
- **5 天闯关计划**：首页有总进度环与今日复习队列（练过但没掌握的知识点自动回炉）。
- **设计依据**：Jolly Phonics 的首组音序（s a t i p n）、英国 DfE *Letters and Sounds* 的 Phase 2–6 推进、Orton-Gillingham 六大音节类型，以及检索练习 / 间隔 / 交错等记忆科学（Roediger & Karpicke 2006、Cepeda 2006、Rohrer 2020）。

## 使用

- 本地：双击 `index.html`。
- 在线：https://wehou.github.io/pindu/

> 5 天是高强度冲刺——目标是建立完整的规则框架、把所有音素过一遍手；之后每天 10 分钟复习两周，才能把规则变成长期记忆。
